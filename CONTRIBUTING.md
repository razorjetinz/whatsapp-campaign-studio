# Contributing

1. Open an issue describing the problem or proposed change.
2. Keep changes focused and include tests for behavioural changes.
3. Run `python -m unittest discover -s tests -v` before opening a pull request.
4. Never commit `.env`, Meta access tokens, phone lists, message content or production database files.
5. Keep opt-in checks, template validation and opt-out handling intact. Changes that weaken these safeguards will not be accepted.

By submitting a contribution, you agree that it may be distributed under the MIT License in this repository.
