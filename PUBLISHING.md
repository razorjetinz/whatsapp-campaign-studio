# Repository publication

This project is published at https://github.com/razorjetinz/whatsapp-campaign-studio.

Clone the public repository with:

```bash
git clone https://github.com/razorjetinz/whatsapp-campaign-studio.git
cd whatsapp-campaign-studio
```

For local development, follow the setup instructions in [README.md](README.md). Do not commit `.env`, customer contact lists, message content or production database files.
